# 交接：独立窗口（v1.9.1 起）

> 2026-10-20（v1.9.0 首发，v1.9.1 随 `pet_set` 同意流程一并发布）。
> 这份是**给使用者的操作指南**；
> 实现细节与踩坑记录见 `standalone-implementation.md`。

---

## 一、怎么用起来

### 1. 装插件

```powershell
# npm（推荐）
dsh plugin --profile <你的profile> add dsh-coopanion-pet@1.9.1

# 或本地 tgz
dsh plugin --profile <你的profile> add "file:D:\path\dsh-coopanion-pet-1.9.1.tgz"
```

装完**必须完全退出 DSH 再重开**（客户端模块要重新装配）。

### 2. 让 Electron 可用（三选一）

独立窗口需要 Electron 运行时（**151 MB**）。它作为 `optionalDependencies` 声明，
npm 安装时会自动带；如果你的环境跳过了可选依赖，或想用已有的那份：

| 方式 | 怎么做 |
| --- | --- |
| **npm 自动** | 什么都不用做（默认） |
| **指定路径** | 设置 → 桌宠 → **Electron 路径**，填 `electron.exe` 的完整路径 |
| **环境变量** | 启动 DSH 前设 `DSH_COOPANION_ELECTRON=<路径>` |

**找不到时**：独立窗口不可用，**但本体照常**（DSH 页面里的她一切照旧），
设置面板会显示「没找到 Electron 运行时」——**如实说，不假装成功**。

### 3. 打开她

三种方式：

| 方式 | 操作 |
| --- | --- |
| **设置面板** | 设置 → 桌宠 → 独立窗口 → **打开** |
| **工具** | 让 Agent 调 `pet_desktop`（`action: 'start'`） |
| **偏好** | 勾上「启动时打开独立窗口」，下次 DSH 一起来她就在 |

## 二、她出现后能做什么

### 鼠标穿透（核心体验）

- **鼠标移到她身上** → 她变成可交互
- **移到她旁边** → 鼠标**穿透到桌面**，能点到底下的窗口

**这是窗口级的穿透**（`setIgnoreMouseEvents(true, {forward:true})` + 命中判定），
不是页面里模拟的。

### 交互

| 操作 | 效果 |
| --- | --- |
| **单击** | 她说话 |
| **拖动** | 把她拖到别处（松手落下，甩得快会晕） |
| **双击** | 打开对话（按偏好设置） |
| **右键** | 弹出窗口菜单（见下） |

### 右键菜单（7 项）

| 项 | 说明 |
| --- | --- |
| 打开 DSH 主窗口 | 在浏览器里打开 DSH |
| **打开对话面板** | 弹出独立聊天面板 |
| 让她说话 | 说一句随机台词 |
| 隐藏直到下次启动 | 临时收起（重启后自动出现） |
| **穿透模式**（勾选） | 勾上 = **永远穿透**，她变成纯装饰 |
| **置顶**（勾选） | 取消 = 她会被别的窗口盖住 |
| 退出桌宠 | 关掉独立窗口（DSH 本体不受影响） |

### 全局快捷键

**`Alt+Space`** —— 唤出/收起她。**DSH 没聚焦时也管用**
（这是独立窗口相比页内热键的优势）。

在设置 → 桌宠 → **唤出/收起快捷键** 里可改。

### 托盘

系统托盘有她的图标：
- **单击** → 唤出/收起
- **右键** → 同一套菜单

## 三、独立聊天面板

**右键她 → 打开对话面板**（或快捷键唤出后从菜单进）。

| 能力 | 说明 |
| --- | --- |
| **会话列表** | 左侧，按最近活动排序，显示**真实标题** |
| **读历史** | 点一条会话，右侧显示消息（用户/她/工具调用） |
| **发消息** | 底部输入框，Enter 发送、Shift+Enter 换行 |
| **等回复** | 发完自动轮询，回复到了就刷新出来 |
| **在 DSH 中打开** | 右上角按钮，切回 DSH 主窗口 |

**关键**：面板与 DSH 主面板操作的是**同一批会话**——
在面板里发的消息，DSH 页面刷新就能看到；反之亦然。

**面板的已知限制**（如实说明）：
- 只做**纯文本 + 换行**，不渲染 Markdown/代码块
- **不支持发图**
- 不做分页（只回最近 200 条）

## 四、设置项在哪

设置 → 桌宠 → 最下面「**独立窗口（桌面上那个她）**」组：

| 项 | 说明 |
| --- | --- |
| 启动时打开独立窗口 | 开/关 |
| 独立窗口状态 | 实时显示「运行中 · 已连上会话」，每 3 秒刷新；旁边有**打开/关闭**按钮 |
| 唤出/收起快捷键 | 默认 `Alt+Space` |
| Electron 路径 | 留空则自动找 |

## 五、架构（一句话版）

```
DSH 宿主进程
  └─ 插件 index.js
       ├─ 本地 bridge 服务（刻意不在 /api 下 → 不走鉴权）
       └─ spawn Electron 子进程
            ├─ 自己的静态服务（镜像 DSH 路由形状 → client.js 一个字没改）
            ├─ 宠物窗口（透明/穿透/置顶）
            └─ 聊天面板窗口
```

**为什么独立窗口里的她能力与 DSH 页面里一样**：她连的是**同一条 `channel`**，
因此 13 个 `pet_*` 工具、状态气泡、语音、CUA 审批**全部照旧可用**。

**DSH 没开时**：她仍会出现（静态资源由 Electron 自己提供），只是没有「Agent 指挥」的能力。

## 六、出问题怎么排查

主进程会写两份日志（DSH 的 logger 不往 stdout 写，因此落到文件）：

| 文件 | 内容 |
| --- | --- |
| `%TEMP%\dsh-coopanion-desktop.log` | **宿主侧 bridge** 的日志（端口、spawn、退出） |
| `%TEMP%\dsh-coopanion-electron.log` | **Electron 窗口**的日志（窗口显示、托盘、快捷键、穿透切换） |

`%TEMP%` 通常是 `C:\Users\<你>\AppData\Local\Temp`。

### 常见现象

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 设置面板显示「没找到 Electron 运行时」 | Electron 没装或路径不对 | 填「Electron 路径」，或 `npm i electron` |
| 窗口不出现，但状态说 `running: true` | 被别的窗口盖住，或 GPU 问题 | 检查 `alwaysOnTop`；试右键菜单「置顶」 |
| 快捷键没反应 | 被别的程序占用了 | 看 electron 日志的 `hotkey ... = FAILED`；改一个键 |
| 她一直在闪 / 拖不动 | 穿透判定异常 | 右键菜单勾「穿透模式」先固定住 |
| 关掉 DSH 后 `electron.exe` 还在 | 进程树没清干净 | 正常路径已用 `taskkill /T /F`；若残留，`taskkill /F /IM electron.exe` |

## 七、已知限制（如实列出）

| 项 | 说明 |
| --- | --- |
| **只在 Windows 验证过** | Linux/macOS 的进程清理走了 `SIGTERM`，**未实测** |
| **无头环境需加参数** | 我的自动化验证用了 `--no-sandbox --disable-gpu --use-gl=swiftshader`；真实桌面不需要 |
| **未做「让位空闲检测」** | takboo 为三平台各写了键盘活动检测；本实现没做——她不会因「你在打字」而让位 |
| **面板不渲染 Markdown** | 纯文本 + 换行 |
| **面板不支持发图** | 没接 DSH 的 `attachment` API |
| **多显示器未做** | 窗口开在主显示器的 workArea 上，跨屏移动没做 |
| **面板主题** | 跟 `prefers-color-scheme`，不跟 DSH 的主题设置 |
| **Electron 体积** | **151.0 MB**（实测） |

## 八、下一步可以做的（按价值排序）
